Google kirish ishlamasay, nima qilish kerak?
Google Client ID to'g'ri kiritilishi kerak. Agar konfiguratsiya bo'lmasa, tizim o'zbekcha xabar bilan ko'rsatadi va foydalanuvchini login qilishdan oldin ma'lumotni to'ldirishni so'raydi.
AI ishlamasa nima bo'ladi?
Agar API kaliti mavjud bo'lmasa, sayt offline bazasi orqali javob beradi. Real model olganda, API kalitini faqat brauzer localStorage'da saqlanadi.
Shaxmat bo'limi haqiqiymi?
Ha, bu interaktiv va qonuniy yurishlarni tekshiruvchi shaxmat taxtasi. Kompyuter qarshi o'yin uchun legal yurishlar orqali random/strategik tanlov qo'llaniladi.
